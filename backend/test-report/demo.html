TC09 – Gửi yêu cầu đặt phòng hợp lệ

PASSED

Kiểm tra đặt phòng thành công: tạo booking với trạng thái pending và tính đúng totalPrice theo công thức: giá phòng × số ngày thuê.

Endpoint

Module
BookingService
Loại test
Happy Path
File
booking.service.spec.ts

Request Payload
// BookingRoomReqDto – userId: 10
{
  "roomId": 1,
  "startDate": "2026-07-10",
  "endDate": "2026-07-13",  // 4 ngày
  "capacity": 2
}
Mock Database State
// Phòng tồn tại, đang active và còn trống
findOne(Room, { where: { id: 1 } }) → {
  id: 1,
  roomNumber: "101A",
  maxPeople: 4,
  price: "150.00",
  status: "active"
}

// Không có booking nào trùng thời gian
createQueryBuilder(Booking).getOne() → null

// Mock clock (jest.useFakeTimers)
fixedNow = "2026-01-01T00:00:00Z"
// startDate / endDate đều sau fixedNow → qua validation ✓
Tính toán totalPrice
startDate = 2026-07-10
endDate   = 2026-07-13
Số ngày   = diff(endDate, startDate) + 1 = 3 + 1 = 4 ngày

totalPrice = 150.00 × 4 = 600.00 ✓

Expected Booking Record
{
  "userId": 10,
  "roomId": 1,
  "roomNumber": "101A",
  "capacity": 2,
  "roomPrice": "150.00",
  "startDate": "2026-07-10",
  "endDate": "2026-07-13",
  "status": "pending",
  "totalPrice": "600.00",  // 150 × 4 ngày ✓
  "createdAt": "2026-06-01T00:00:00.000Z"
}
✅
Kết quả thực tế
Booking được tạo với status: "pending" • totalPrice: "600.00" tính đúng • Transaction commit thành công
